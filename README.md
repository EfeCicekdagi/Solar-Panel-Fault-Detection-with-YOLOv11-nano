# 🌞 Solar Panel Fault Detection with YOLOv11

This project aims to detect faults on solar panels (such as dust, birds, electrical, physical, and snow-related issues) using the **YOLOv11** deep learning model.

├── Data/ # Dataset (images, labels, data.yaml)
├── train.py # Training script
├── test.py # Evaluation script
├── runs/ # Training outputs (weights, logs)
